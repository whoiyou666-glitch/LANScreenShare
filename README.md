# LANScreenShare — экран через интернет одной командой

Работает на Windows 10/11 (64 бит). Не нужны Tailscale, установка Python, регистрация Cloudflare, настройка роутера или открытие портов.

## Одна команда — на компьютере, экран которого хотите показывать

Откройте PowerShell, вставьте:

```powershell
$p="$env:TEMP\LANScreenShare-Start.ps1"; Invoke-WebRequest 'https://raw.githubusercontent.com/whoiyou666-glitch/LANScreenShare/main/Start-Anywhere.ps1' -UseBasicParsing -OutFile $p; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p
```

Скрипт автоматически скачает приложение из этого репозитория, скачает официальный cloudflared (один раз, с проверкой SHA-256), создаст временный HTTPS-туннель и покажет персональную ссылку.

## На втором компьютере

Просто откройте **полную ссылку** из окна первого ПК, включая часть после `#`. Отдельный код вводить не требуется. На втором ПК достаточно обычного браузера, дополнительных программ не нужно.

Остановить трансляцию: нажмите **Enter** в окне первого ПК. Закрытие окна также прекращает локальную трансляцию.

## Безопасность и ограничения

- Приложение показывает весь экран, включая все мониторы. Передавайте ссылку только доверенным людям.
- Ссылка содержит случайный 128-битный ключ, новый для каждого запуска. Запросы кадров без него отклоняются.
- Сервер слушает только `127.0.0.1`, снаружи доступен через временный HTTPS-адрес Cloudflare.
- Cloudflare обрабатывает трафик туннеля. Для конфиденциальных данных используйте доверенный VPN.
- Установка в автозагрузку, скрытый запуск, управление клавиатурой/мышью, передача звука или файлов отсутствуют.
- Cloudflare Quick Tunnel предназначен для тестов и не гарантирует стабильную доступность. После перезапуска ссылка меняется.
- Пока не тестировалось на настоящей Windows: при ошибке отправьте текст из PowerShell.

## Дополнительные способы (не нужны для одной команды)

- `Start.cmd` — доступ по локальной сети.
- `Start-Internet.cmd` — просмотр через Tailscale, если он уже установлен на двух ПК.
- `Allow-Tailscale-Firewall.cmd` — настройка Windows Firewall только для режима Tailscale.
- `Start-ScreenShare.ps1` — основной сервер просмотра.
- `Start-Anywhere.ps1` — автоматический режим без предварительной установки.

Используйте только для своих компьютеров или с разрешения владельца.
