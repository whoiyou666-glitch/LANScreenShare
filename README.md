# LAN Screen Share — Windows 10/11 (LAN + Internet)

Простая **видимая** трансляция изображения всех мониторов Windows с одного компьютера на другой через браузер. Только просмотр; звук, клавиатура, мышь, файловые операции и скрытый запуск отсутствуют.

Ключ доступа генерируется **заново при каждом запуске**, никому автоматически не передаётся и не сохраняется. Если PowerShell остановлен, трансляция прекращается. Программа не работает как служба и не добавляет автозагрузку.

## Режим 1: через интернет из любой точки мира (Tailscale)

1. На **обоих** компьютерах установите [Tailscale](https://tailscale.com/download/windows). Или в PowerShell: `winget install -e --id Tailscale.Tailscale`.
2. На обоих компьютерах выполните вход в **одну приватную сеть Tailscale (tailnet)**. Используйте свои устройства или выдайте другому пользователю разрешение в Tailscale.
3. На **первом компьютере**, экран которого хотите смотреть, запустите `Start-Internet.cmd` (или `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-ScreenShare.ps1 -Tailscale`).
4. Программа выведет адрес вроде `http://100.101.102.103:8765/` и случайный код доступа. На **втором компьютере** откройте этот адрес и введите код.
5. Если с второго компьютера страница не открывается, на **первом** компьютере однократно нажмите правой кнопкой `Allow-Tailscale-Firewall.cmd` → **Запуск от имени администратора**. Он добавляет правило Windows Firewall, разрешающее только TCP 8765, только на Tailscale-адрес этого компьютера, только от адресов Tailscale `100.64.0.0/10`.
6. Когда просмотр не нужен, нажмите Ctrl+C или закройте окно с трансляцией. Для удаления правила брандмауэра можно запустить в PowerShell администратора:

   ```powershell
   Remove-NetFirewallRule -DisplayName 'LAN Screen Share (Tailscale port 8765)'
   ```

Трафик между устройствами шифрует Tailscale. Хотя URL начинается с `http://`, он работает **только через частный Tailscale-интерфейс**, а не через открытый интернет. Сервер не слушает домашний LAN-адрес в режиме Tailscale. Нельзя открывать порт 8765 на роутере или выключать брандмауэр целиком.

## Режим 2: через домашний LAN

На первом ПК запустите `Start.cmd`, на втором откройте адрес `http://192.168.x.x:8765/`, показанный в терминале, и введите код. При необходимости настройте Firewall для частной домашней сети. Не выставляйте обычный LAN-режим в интернет.

## Загрузка на GitHub

1. Создайте пустой репозиторий **LANScreenShare** через https://github.com/new (может быть Public или Private).
2. Внутри GitHub откройте `Add file` → `Upload files` и загрузите **файлы из этой папки**, а не только архив: `Start-ScreenShare.ps1`, `Start-Internet.cmd`, `Start.cmd`, `Allow-Tailscale-Firewall.ps1`, `Allow-Tailscale-Firewall.cmd`, `README.md`. Нажмите `Commit changes`.
3. Для скачивания одной командой в PowerShell на первом ПК выполните (замените `whoiyou666-glitch` на свой логин GitHub):

   ```powershell
   $user = 'whoiyou666-glitch'
   $zip = "$env:TEMP\LANScreenShare-main.zip"
   $dir = "$env:TEMP\LANScreenShare-install"
   Invoke-WebRequest "https://github.com/$user/LANScreenShare/archive/refs/heads/main.zip" -OutFile $zip
   Expand-Archive -LiteralPath $zip -DestinationPath $dir -Force
   & "$dir\LANScreenShare-main\Start-Internet.cmd"
   ```

   Если репозиторий **Private**, обычная анонимная ссылка не скачает его; потребуется авторизация. Если основная ветка названа не `main`, исправьте её название в команде.

Проверяйте содержимое скачанных скриптов перед запуском. Не вставляйте неизвестные команды из интернета в PowerShell.

## Требования и ограничения

- Windows 10/11, встроенный Windows PowerShell 5.1, .NET Framework; Python не нужен.
- Для режима интернет нужен Tailscale на обоих устройствах и доступ между ними, разрешённый правилами tailnet.
- Примерно 1 кадр в секунду; это не потоковое видео с высокой частотой кадров.
- Передаются все мониторы. Не оставляйте на экране пароли, банковские данные и личные переписки, если за просмотром кто-то ещё.
- Пока компьютер не включён, не подключён к интернету или приложение не запущено, трансляции нет.
- При блокировке Windows изображение может быть чёрным.
- Приложение предназначено только для своих устройств либо устройств с явным разрешением владельца.
- Протестировано статически, но пока **не протестировано на реальной Windows**; могут потребоваться настройки брандмауэра и разрешения Tailscale.
