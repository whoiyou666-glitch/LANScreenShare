# LANScreenShare — просмотр экрана одной командой

Только Windows 10/11 (64 бит). Одна команда в **PowerShell** запускает видимую трансляцию экрана через Интернет. На втором устройстве нужно только открыть защищённую HTTPS-ссылку в браузере. Не нужно устанавливать Tailscale, настраивать роутер, открывать порты или регистрироваться в Cloudflare.

## Запуск (ОДНА команда)

Вставьте в **PowerShell на компьютере, экран которого будете показывать**:

`powershell
$p="$env:TEMP\LANScreenShare-Start.ps1"; Invoke-WebRequest 'https://raw.githubusercontent.com/whoiyou666-glitch/LANScreenShare/main/Start-Anywhere.ps1' -UseBasicParsing -OutFile $p; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p
`

Приложение само:
1. Скачает основной скрипт с этого репозитория.
2. При необходимости скачает официальный cloudflared с GitHub Cloudflare, проверит SHA-256 и сохранит в \`%LOCALAPPDATA%\LANScreenShare\`.
3. Создаст временный HTTPS-адрес через Cloudflare Quick Tunnel.
4. Запустит сервер **только на 127.0.0.1**, а на экране выведет ссылку вида \`https://example.trycloudflare.com/#СЕКРЕТНЫЙ_КЛЮЧ\`.

На втором компьютере (или телефоне) **ничего устанавливать не нужно**: откройте полную ссылку, в том числе часть после \`#\`. Она содержит случайный код доступа, поэтому вводить пароль отдельно не нужно.

Чтобы завершить сеанс, нажмите **Enter** в окне с трансляцией или закройте его. Следующий запуск создаёт новый секретный ключ и новую ссылку.

### Важно о безопасности

- Сервер привязан только к loopback \`127.0.0.1\`; локальный порт не выставляется напрямую в Интернет.
- Доступ к кадрам возможен только с новым случайным 128-битным ключом. Ключ находится во фрагменте URL и браузер отправляет его в заголовке запроса при получении кадра.
- По HTTPS изображение проходит через инфраструктуру Cloudflare. Для особо секретных экранов используйте собственную проверенную VPN или систему удалённого доступа.
- **Никому постороннему не передавайте ссылку**: каждый, у кого она есть, может смотреть все мониторы, пока сеанс открыт.
- Запуск только вручную и в открытом окне PowerShell; нет скрытого режима, службы, автозагрузки, доступа к клавиатуре/мыши или файлам. Звук не передаётся.
- Cloudflare Quick Tunnel предназначен для тестирования, не гарантирует непрерывной доступности. Новый сеанс получает новую ссылку. Для постоянного адреса нужен другой режим размещения.
- Приложение ещё не тестировалось на реальном Windows 10/11. При ошибке приложите текст консоли.

## Альтернативные режимы

Скачайте репозиторий целиком и запустите \`Start.cmd\` для домашней сети или \`Start-Internet.cmd\` для приватной сети Tailscale (требует Tailscale на обоих компьютерах).

Для режима Tailscale, если Windows Firewall препятствует соединению, используйте \`Allow-Tailscale-Firewall.cmd\` от имени администратора. В режиме **одной команды** он НЕ нужен.

## Исходный код

- \`Start-Anywhere.ps1\` — автоматическая загрузка cloudflared и запуск через Интернет.
- \`Start-ScreenShare.ps1\` — видимая трансляция и просмотр через браузер.
- \`Start.cmd\` / \`Start-Internet.cmd\` — дополнительные режимы.
- \`Allow-Tailscale-Firewall.ps1\` / \`.cmd\` — правило брандмауэра только для Tailscale.

Трансляция предназначена для собственных устройств и устройств с разрешения владельца.
